# DukkanApni

DukkanApni is a Python-based shop management
application that runs in the terminal.

## Features

- Add and view products
- Search products
- Generate customer bills
- Update stock after sales
- View sales reports
- Save products and sales data using JSON
- Reset sales report

## Technologies

- Python
- JSON
- File Handling

## How to Run

1. Install Python 3.
2. Open Terminal in the project folder.
3. Run:

   python3 main.py
